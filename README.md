# Sin prisa, pero con alma

Web oficial de **Sin prisa, pero con alma**.

Proyecto artesanal para mostrar colecciones, novedades y encargos personalizados de bordados, complementos y detalles para eventos.

## Arquitectura inicial

- Inicio / novedades
- Colecciones
- Encargos
- Sobre mí
- Contacto

La primera versión se publicará como sitio estático en GitHub Pages. La arquitectura queda preparada para conectar más adelante dominio y CDN mediante Cloudflare y servicios privados alojados en mini PC mediante Cloudflare Tunnel.
